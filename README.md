# 星野宇潮のWeb名刺

スマートフォンでプロフィールと連絡先をすぐ確認できる、1列の静的サイトです。

- 公開URL: https://ushikundesuyo.github.io/my-social-links/
- 公開元: GitHub Pages / main ブランチのルート
- HTML: index.html、スタイル: styles.css、機能: script.js
- ビルド不要、外部表示ライブラリ不要。

## 現在の構成（2026-09-17）

1. 顔を大きく表示した写真、星野宇潮、読み仮名、資格・所属。
2. 仕事の相談・お問い合わせ。
3. LINE / Facebook / Instagram / X。
4. 折りたたみ式「活動・会社について」。会社と実績は公式サイトへ。
5. ページのリンクをコピー。

大きなコピー、ページ内メニュー、メンバー紹介、実績カード、FAQの長い構成を、本人のスマホ優先・簡潔化の依頼で整理。元の内容はGit履歴に保存されています。

## 確認

- 390×844pxで問い合わせ・4つのSNSが最初の画面内に表示。
- 320px幅でも横はみ出しなし。主要操作は高さ48px以上。
- 写真表示、リンクコピー完了表示、キーボードによる会社紹介の開閉を確認。
- JavaScriptなしでも本文・SNS・問い合わせ・会社紹介の開閉を利用可能。
- ローカルファイル・アンカー・ID重複・外部リンク保護を検証。
- SNSのログイン後操作やLINEの友だち追加自体は実施しません。

## プレビュー

```sh
python -m http.server 8769 --bind 127.0.0.1
```

http://127.0.0.1:8769/ を開きます。

## 写真と情報

写真は本人指定の公式プロフィール写真 `/assets/images/hoshino-formal-20260818.jpg` を `assets/ushikun.jpg` に保存。写真自体は加工せず、CSSで顔を中心に3倍表示。会社・事業情報は https://invaders.co.jp/ の公開内容を2026-09-17に確認しました。

Instagramは公式サイトに掲載された現行プロフィール `ushikun_desu` へ修正済み。X・Facebook・LINEのURLは従来の本人指定先を維持。

assets内の他の写真は前デザインの履歴用で、現在のページからは読み込みません。

更新時はCSS/JSのクエリ文字列も更新して、旧版のブラウザーキャッシュを避けます。
